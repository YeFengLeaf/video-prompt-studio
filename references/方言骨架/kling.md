# 方言骨架 · Kling 4.0

> 来源：`references/03_模型适配.md` §7。骨架文件：只复述档案，不新增参数。证据等级 **A（Kling 官方 4.0 用户指南，2026-10-27 复核）**。原 C 级项目约定（10s 级/`@element1`/未核实）已作废。旧版（如 3.0）参数不同，出包前须先确认版本。

## 档案（Kling 4.0，官方指南）

- 单条上限：3–30 秒（默认 10 秒）（A）
- 画幅：21:9 / 16:9 / 1:1 / 9:16 / Auto（默认 Auto）（A）
- 分辨率：720p / 1080p / 4K（A）
- 参考输入：≤10 图 / ≤5 视频（合计 ≤30 秒）/ ≤7 元素（含 ≤3 视频元素）/ ≤3 声音档案 / 合计 ≤15；最多 10 个关键帧（A）
- 音频：原生立体声（2 声道），支持对白口型同步（A）
- 引用语法：`@Image1` / `@Video1` / `@Element1`（首字母大写）——**不要**写 `图1`（与 Seedance 语法冲突，项目约定保留）
- 参数位置：提示词外（A）

## 使用规则

- 素材按上传顺序自动编号，每个素材必须写清用途；只写素材编号不写用途时模型自行推断，结果不可预测。
- 不得把本文件内容写成旧版或其他版本的参数；平台改版后，以新核验日期与证据等级为准。
