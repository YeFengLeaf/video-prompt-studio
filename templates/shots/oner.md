# 镜头模式 · 一镜到底

## 何时用

- 空间本身是信息（走廊、楼梯、街区）；
- 表演连续不能切；
- 品牌/产品需要"一气呵成"。

## 四要素（缺一不可）

1. **起点**：机位在什么位置、看到什么
2. **路径**：按顺序经过哪些空间/人物
3. **揭示**：每个新信息出现的位置
4. **收束**：停在哪、最后画面

## 提示词骨架

```text
一镜到底，无剪辑。
机位从{{camera_start}}开始，{{first_view}}。
沿{{path}}移动，经过{{point_1}}、{{point_2}}，在{{reveal_point}}揭示{{new_info}}。
最后停在{{camera_end}}，画面{{ending_frame}}。
{{shot_size}}起，{{lens}}，{{speed_note}}。
声音：{{ambience_path}}（随空间变化）。
```

## 参数建议

- 15s 内最多 2–3 个信息点；30s 最多 3–4 个。
- 不写"镜内切/跳视角/换焦段"；需要换就切条。
- 机位高度与路径要明确，否则模型会自己飘。

## 失败风险

| 风险 | 改法 |
|---|---|
| 中途穿帮 | 减少经过点，路径写直 |
| 变成多个镜头 | 明确"无剪辑"，不写切 |
| 空间混乱 | 先画一张俯视路径图再写 |
| 30s 太贵 | 先做 15s 版本测动作 |
