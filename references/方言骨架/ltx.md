## 档案

- 单条上限：时长档 6/8/10/12/14/16/18/20s（1080p），高帧率/高分辨率档缩至 6/8/10s；Fast 档最长 20s@1080p/25fps（062，A）
- 画幅：比例仅 16:9 与 9:16（062，A）
- 分辨率：1080p / 1440p / 4K 三档；开源推理分辨率须被 32 整除（060/062，A）
- 参考输入：首尾帧控制（LTX-2.3，062，A）；多条件生成 `--conditioning_start_frames`（061，A）
- 音频：同步音频生成（LTX-2，062，A）；六要素含 Describe the Audio（059，A）
- 引用语法：自然语言六要素段落（无 `@` 式语法）
- 参数位置：提示词内为六要素正文；API 参数（分辨率/帧率/时长）另行

## 结构顺序（六要素，单一流动段落，现在时，4–8 句）

```text
① Establish the Shot → ② Set the Scene → ③ Describe the Action → ④ Define Characters → ⑤ Identify Camera Movement(s) → ⑥ Describe the Audio
```

## 写法规则

- 单一流动段落；现在时动词；细节密度匹配景别（特写比大远景更细）；相机运动相对主体描述（059）。
- 情绪用身体动作表达，不写抽象标签如 sad（059）。
- 开源参数：帧数须为 8n+1（如 257）；最佳区域 <720×1280 像素、<257 帧；Guidance Scale 3–3.5；步数 40+ 求质量、20–30 求速度；seed 可保存复现构图；不满足整除条件时输入先 -1 填充再裁剪（060）。
- distilled 模型（0.9.6/0.9.7/0.9.8）不要求 CFG/STG，推荐采样 8 步；扩展输入段长须 8n+1，目标帧数须 8 的倍数（061）。
- Fast 变体适合分镜迭代；Pro 变体为 audio-to-video / retake / extend 端点必需（062）。
