# 镜头模式 · 对话正反打

## 何时用

- 有台词，且说话人切换；
- 需要看听者反应；
- 两人对峙/谈判/告别。

## 结构

```text
A 镜（过 B 肩拍 A）：A 在画面右三分之一，视线朝左
B 镜（过 A 肩拍 B）：B 在画面左三分之一，视线朝右
反应镜：听者近景，0.5–1.5s
```

## 提示词骨架

```text
{{speaker_a}}在画面右三分之一，视线朝左，{{emotion_action}}。
[{{speaker_a}}]（{{tone}}）：「{{line_a}}」
镜头：中近景，过{{speaker_b}}肩，50–85mm，固定。
声音：{{ambience}}；人声清晰。
```

## 参数建议

- 景别匹配：两条都中近景或都近景。
- 台词按 4.5 字/秒；长台词中途切反应镜。
- 单条里不要完成"正反打 + 走位 + 换场"，会超时。

## 失败风险

| 风险 | 改法 |
|---|---|
| 两人左右互换 | 每镜明确写"画面右/左" |
| 台词串人 | 每条标 `[说话人]` |
| 口型对不上 | 正脸近景 + 缩短台词 |
| 像念稿 | 加一个听者反应动作 |
