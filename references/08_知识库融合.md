## 1. STYLE LOCK：整片摄影基调锁死（M1）

把「画风」写成一段**固定不变的英文摄影口令**，每个镜头粘贴在开头。壳结构（示例壳，三要素按题材替换，不得照抄当通用默认值）：

```text
[STYLE LOCK]
Shot on {{film_stock}} film stock + analog film grain visible +
practical light only + {{director}} cinematography + {{director}} painterly
desaturation + photochemical film texture + slight halation + organic film noise
+ heavy atmospheric haze + dust particles + film print look not digital cinema +
photorealistic film still aesthetic + NOT 3D render.
```

示例壳（方法示例，导演/胶片/工艺三要素已按示例题材填写）：

```text
[STYLE LOCK]
Shot on 35mm Kodak Vision3 500T film stock + analog film grain visible +
practical light only + Christopher Doyle cinematography + Wong Kar-wai painterly
desaturation + photochemical film texture + slight halation + organic film noise
+ heavy atmospheric haze + dust particles + film print look not digital cinema +
photorealistic film still aesthetic + NOT 3D render.
```

要点：用**导演 + 胶片 + 后期工艺**（人名 / 胶片型号 / 化学工艺）而非形容词；并显式 `NOT 3D render` 防跑偏。换镜头换段，LOCK 不换。可组合模板见 `templates/styles/style-lock.md`。

画质基线句（与 STYLE LOCK 并用时不得重复堆叠同义画质词，见 `references/09_去AI感策略库.md` 类别 1）：

```text
电影画质：超写实电影级摄影，电影布光，胶片电影质感，ARRI Alexa 65 电影机拍摄，
不要有太多细碎的纹理色块，不要有过度的阴影细节，不要有太细碎的阴影和纹理。
```

## 2. 方法论 M2–M10（摘要，通用逻辑完整保留）

### M2 · 段级色卡：跨段共享 + 段新增

```text
色卡 = 共享色（若干，锁定系列）+ 段内新增色（若干，只服务本段前景）
每个色 = 命名 + hex + 归属物
```

- 用「公共底 + 局部增量」保证多段镜头颜色统一，而不是每段重新调色。
- 色卡是 prompt 里的「最高法」：视频生成时写明「严格按色卡执行，不可偏离色板」。
- 冲突提示：后续口径改为取消色板图、改由材质锚定保证颜色一致；新项目优先用材质锚定，色卡仅在多段强一致需求时启用。两者取舍须在决策摘要写明。

### M3 · 锚定图三件套（身份 / 场景 / 色彩）

一段视频可堆多张引用，按职责分：

- **场景锚**：`@[场景图] 作为视觉强场景一致性锚定 + [建筑 / 地面材质] 严格按此图渲染`——锁背景。
- **角色锚**：`@[人设图] 作为[形态]的视觉锚定，[精确造型清单]严格按此图渲染 + 仅[镜头范围]出现`——锁角色并隔离。
- **色卡锚**：`@[色卡] 所有色彩严格按色卡执行，不可偏离色板`——锁色。
- **姿态参考**（弱锚）：`仅作场景与角色身份参考，非首帧严格复刻`——锁身份不锁动作。
- 引用语法 `@[…]` 为一种模型方言，目标模型引用语法以 `references/03_模型适配.md` 为准。

### M4 · 角色一致性链：人设 → 首帧 → 视频

```text
人设四视图（9:16 单侧光）→ 关键帧 / 首帧（STYLE LOCK 镜头）→ 视频生成（@[锚定]）
失败支路：取帧 → 生成修图（短句）→ 再回锚
```

四视图特意留一张**无脸全身**（头裁出画框，后续换脸不重画）——把 AI 管线当成可迭代的资产库来设计。四视图比例与光位为项目口径，可按题材调整，须在决策摘要写明。

### M5 · 长视频 = 时间轴分镜脚本

一镜到底不写一句话，而写分段时间轴（格式示例，内容为通用占位）：

```text
2-4s match cut 切上帝视角俯拍，[主体动作]向外扩散
4-6s 切[角色] POV，[次要主体]逼近，wide shot
6-9s 侧面跟拍，motion blur，两侧扭曲透视倾斜
```

每段给「镜头语言 + 内容 + 氛围细节」，视频模型按序执行，比单句稳定。

### M6 · 否定句钉死运动学（防 AI 偷懒）

格式：`[主体][精确数值节奏] + 绝对不能渲染成[偷懒形态 A] + 绝对不能渲染成[偷懒形态 B]`。

```text
[主体]每秒 3–4 步独立节奏 + 绝对不能渲染成缓慢移动 + 绝对不能渲染成静止
```

AI 视频倾向静态、慢速。用**精确数值 + 绝对否定**写运动。

- 边界（D 级，未核实）：否定句对静态约束基本失效——「完全不动」「没有雨」类空泛否定易被忽略，须改写为正面状态描述（见 `references/09_去AI感策略库.md` 类别 4）。M6 适用于运动学否定，不适用于静态约束。

### M7 · 差量修图：一句话 + 边界

`动词 + 唯一对象 + "除此之外不要做任何改动"`：

- `去掉视频里[某物]，不要做任何其他改动`
- `去掉画面里的人。其他不变。`

边界句防止「顺手改全局」。修图与主生成建议分工：修图用快速模型，主生成用强模型（工具选型未核实）。

### M8 · 风格混搭语法（导演坐标系）

用**具体电影 / 名导 / 名场面**做坐标，给 AI 最密集的风格锚，比编形容词准。示例格式：

```text
[影片 A] kinetic chase + [导演 B] painterly desaturation +
[导演 B] cinematography + [导演 C]《[影片]》…
```

引用在世导演作品与具体片名时注意版权与评价分寸。

### M9 · meta 嵌套叙事（片场收尾）

把整片**框进监视器**（摄影棚一镜横向跟拍至监视器画框；whip pan 转化妆间镜子 POV）——一部作品里同时存在「拍出来」和「正在拍」两层世界，转场即世界观切换。策划主线 / 花絮线两条线时，用「监视器 / 镜子」这类实体当转场锚。

### M10 · prompt 工程组织法

| 层级 | 载体 | 作用 |
|---|---|---|
| 风格层 | STYLE LOCK 英文段 | 全片基调 |
| 结构层 | 分段标题 | 让 prompt 可读、可复用 |
| 锚定层 | @[asset] + 归属说明 | 素材管理 |
| 时间层 | 0–2s 分段 | 一镜到底的剧本化 |
| 修正层 | 短句差量 | 迭代 |
| 命名层 | 关键帧标题（段 + 机位 + 动作） | 索引 |

**一句话**：把 AI 视频制作当成**可以审的工程文档**来写，而不是「灵感句子」。

## 3. 单项目方法卡通用规则摘要（去绑定）

> 以下 7 组规则摘要自 7 张单一项目验证的方法卡（C 级，未核实）。卡片原文含源项目题材绑定与原文引用，**未并入本 Skill**；此处只保留去绑定后的通用规则，跨场景使用前须按 `references/04_素材与引用.md` §11 的「待验证」对待，不得当作已验证资产交付。

1. **首尾帧脚本化 + 克制差量句**：首尾帧用固定句式写（起幅构图三要素 + 收幅构图三要素 + 中间只写运镜衔接）；差量句先列「不动维度」白名单（五官 / 发型 / 光线 / 调色 / 构图），再写唯一诉求。不写边界的差量句等于授权模型全图重画。
2. **分轨风格壳 + 模型分工思路**：长篇为不同戏路各配一个壳，不用一段万能画风戳到底；壳与壳之间靠起幅/收幅与硬切拼接。模型分工只迁移「分工思路」，具体模型名与版本须按 `references/03` 参数表重新核验。
3. **音轨四层 + 变身一句交底**：音轨段分四层（配不配 BGM / 底层氛围音 / 叠加动作拟音 / 声音随时间轴变速同步）；变身桥段用「两张图 + 一句类型词」交底，类型词必须写明，不得只给两张图让模型猜。
4. **造物设计图四视图格式**：格式行先行（画幅 / 分格 / 背景 / 光位），再写造物设定；设定只写「种属 + 结构」，不写剧情；新资产的光影质感须与资产库现有资产一致。造物一旦入库，后续镜头只引用、不重画。
5. **接续生成 + 约束同条**：接续条第一句写明「接着生成 + 内容连贯」并点名参考对象；硬约束（无字幕 / 无文字 / 不单独给光源 / 运动遵循物理规律）与镜头内容写在同一条里，约束只列具体 artifact；方言台词与说话人、语气写在同一条，台词逐字保留。
6. **影像底座双通道 + 素材位置化占位**：镜头语言用固定英文 look 段锁基调，音效类指令用中文直给，双通道分工；素材填到指定句子槽位（谁在哪个位置、以什么景别出现），占位思想可迁移、平台符号须按目标模型方言替换。配乐写情绪时间轴 + 负向音乐观（提前写明「不要什么」与情绪转折时间点）。
7. **背影规避 + 环境音同条 + 透视清晰度**：不露脸时写清「背影/侧影 + 具体动作 + 服饰特征」，不只写「不露脸」；无 BGM 时写明替代声源与清晰度；远景人物「可以不够清晰」只在符合透视逻辑（远 + 介质遮挡）时成立，须显式写出许可，近景不得援引。
