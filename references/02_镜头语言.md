# 02 · 镜头语言

> 目标：让每一镜都有**可执行的理由**，而不是堆形容词。
> 用法：先定"这一镜要完成什么"，再从下表选景别/焦段/机位/运镜；不要反过来先选运镜再找理由。

---

## 1. 景别

| 景别 | 画面范围 | 主要用途 | 常见错误 |
|---|---|---|---|
| 远景 | 环境为主，人很小 | 交代空间、规模、孤立感 | 主体看不清还硬塞动作 |
| 全景 | 全身 + 周围环境 | 动作完整、走位、空间关系 | 环境太杂，主体被吞 |
| 中景 | 腰部以上 | 对话、日常动作、关系 | 手势被裁掉一半 |
| 中近景 | 胸部以上 | 情绪 + 少量动作 | 与中景混用，节奏无变化 |
| 近景 | 肩部以上 | 表情、反应、台词 | 动作戏用近景，看不清 |
| 特写 | 脸/手/物局部 | 情绪爆点、关键道具 | 连续特写，观众失去空间感 |

**规则**：
- 同一段内景别要有变化，但变化要服务信息，不是为变而变。
- 动作复杂 → 全景/中景；情绪转折 → 近景/特写。
- 一条 15 秒里连续 5 个特写，观众会不知道人在哪。

---

## 2. 焦段（35mm 等效）

| 焦段 | 透视 | 用途 | 副作用 |
|---|---|---|---|
| 18–24mm | 强广角，边缘拉伸 | 空间压迫、主观视角、狭窄室内 | 人脸变形，不适合特写 |
| 28–35mm | 轻广角，环境感 | 跟拍、街头、纪实 | 背景容易抢戏 |
| 50mm | 接近人眼 | 通用、对话、中景 | 平淡，缺风格 |
| 65–85mm | 轻压缩，背景柔化 | 人物近景、情绪、产品 | 空间关系变弱 |
| 100–135mm | 强压缩 | 特写、隔离主体、压缩人群 | 需要距离，AI 里易写成"背景虚化一片" |

AI 视频里焦段词是**提示**不是精确参数：写 `85mm portrait lens, shallow depth of field` 比写 `f/1.4` 更有效；不要写具体光圈值冒充技术参数。

---

## 3. 机位与角度

| 角度 | 心理效果 | 什么时候用 | 什么时候别用 |
|---|---|---|---|
| 平视 | 中性、平等 | 对话、纪实 | 需要压迫/崇拜时 |
| 俯视 | 弱小、被审视 | 失败、被围、上帝视角 | 英雄登场 |
| 仰视 | 强大、威胁 | 反派、权威、建筑 | 日常对话（会显得怪） |
| 低角度贴地 | 速度、冲击 | 奔跑、车、动物视角 | 静态对话 |
| 高角度航拍 | 规模、孤独 | 开场、转场、结尾 | 私密情绪 |
| 过肩 | 关系、对峙 | 正反打、谈判 | 单人独白 |
| 主观视角 POV | 代入 | 恐怖、沉浸、发现 | 需要看清主角表情时 |

**机位三件事必须写**：高度（眼平/胸平/膝平/地面）、方向（正面/侧面/背面/斜 45°）、距离（远/中/近）。只写"俯拍"不够。

---

## 4. 运镜

| 运镜 | 动机 | 建议时长 | 失败风险 |
|---|---|---|---|
| 固定 | 让观众看清 | 任意 | 无 |
| 缓推 | 靠近情绪/真相 | 3–8s | 推太快变"zoom"，透视不对 |
| 拉远 | 揭示环境/孤立 | 3–8s | 拉太远主体消失 |
| 横移 | 展示空间/并置信息 | 2–6s | 速度不匀，画面抖 |
| 跟拍 | 跟随主体移动 | 3–10s | 主体出画、背景糊 |
| 升降 | 揭示规模/俯仰转换 | 3–8s | 中途变焦，逻辑断 |
| 环绕 | 强化人物/产品 | 4–10s | 背景穿帮、人物变形 |
| 手持 | 紧张、真实 | 2–6s | 晃到看不清动作 |
| 变焦推拉 | 眩晕、心理冲击 | 1–3s | 滥用；一镜最多一次 |
| 一镜到底 | 连续空间/长表演 | 10–30s | 中途换机位=穿帮 |

**规则**：
1. 一镜**一个主运镜**。写"推+摇+环绕+变焦"等于没写。
2. 运镜要有动机：跟着谁、揭示什么、停在哪。
3. 运镜起点、路径、终点都要写；只写"镜头推进"模型会自己乱走。
4. 一镜到底内**不许换机位/切视角**；需要换就切镜。

---

## 5. 构图

| 构图 | 用法 | 一句话写法 |
|---|---|---|
| 三分法 | 通用 | 主体位于画面右三分之一，视线朝左留白 |
| 中心构图 | 仪式感、对称、产品 | 主体居中，背景轴对称 |
| 前景遮挡 | 层次、偷窥感 | 前景虚化树叶，人物在缝隙中 |
| 负空间 | 孤独、压迫 | 人物贴画面左下，大片空墙 |
| 引导线 | 纵深 | 走廊透视线收向人物 |
| 框中框 | 窥视、困住 | 门框/车窗把人物框住 |

写构图时同时写**视线方向**（向左看/向右看）和**画面留白侧**——这两项决定正反打能不能接上。

## 6. 时间轴

### 6.1 单条时间轴（每条从 0s 开始）

```text
0–3s：建立（谁、在哪、什么状态）
3–8s：推进（主动作开始，出现阻力）
8–12s：转折/揭示（信息变化或情绪拐点）
12–15s：收束（落点画面，可停 0.5–1s 给反应）
```

不是固定四段，是**检查清单**：是否建立了空间？动作有没有起点？有没有变化？最后停在哪？

### 6.2 节拍密度

- 一个主动作 ≈ 2.5–4 秒（含起势与落点）。
- 15 秒里塞 6 个以上主动作 → 平均每个不到 2.5 秒，模型会糊。
- 对白镜按字数算：4.5 字/秒，另留 0.5 秒呼吸。
- 情绪转折需要"反应时间"：关键台词/动作至少提前 1–2 秒结束，留余韵。

### 6.3 时间码写法

- 中文包：`0–3s：…`（用短横线，不用 `~`）
- MiniMax H3：`[Shot 2] At 00:03.500, the camera cuts to…`（必须严格递增、两位小数）
- 其他模型：时间码只用于内部规划，**不写进最终提示词**（模型不吃这个格式）

## 7. 剪辑与转场

| 方式 | 用法 | 注意 |
|---|---|---|
| 硬切 | 默认；同场景换景别 | 轴线不能跳 |
| 匹配剪辑 | 形状/动作相似转场 | 前后镜运动方向要接 |
| 动作接动作 | 前一镜动作未完，后一镜接住 | 出点/入点状态必须写 |
| 空镜过渡 | 换时间/换地点 | 空镜也要有信息，不是凑数 |
| 一镜到底 | 连续空间 | 不切；靠运镜与人物走位换构图 |

**轴线规则**：两人对话，摄影机不能越过两人连线，否则观众会觉得两人突然换了位置。AI 生成尤其容易犯——**每镜写明人物在画面左/右**。

---

## 8. 正反打（对话标配）

```text
A 镜（过 B 肩拍 A）：A 在画面右三分之一，视线朝左
B 镜（过 A 肩拍 B）：B 在画面左三分之一，视线朝右
```

- 两条的景别要匹配（都中近景，或都近景）。
- 说话人切换时，听者的反应镜比说话人镜头更有信息量。
- 长台词中途切一次反应镜，比一镜到底更有节奏。

---

## 9. 一镜到底

适用：空间展示、长表演、追逐、仪式感。

写法四要素：
1. **起点**：机位在哪、看到什么
2. **路径**：经过哪些空间/人物，按顺序
3. **揭示**：路径上每次"新信息"出现的位置
4. **收束**：停在哪、最后画面是什么

禁止：
- 镜内切机位、跳视角、换焦段（除非写"变焦"且只一次）
- 路径上塞太多事件（30 秒最多 3–4 个信息点）
- 只写"一镜到底"不写路径

## 10. 常见错误清单

| 错误 | 后果 | 修法 |
|---|---|---|
| 一镜堆 3 个运镜 | 模型随机选一个或全糊 | 留一个主运镜 |
| 只写景别不写机位 | 角度随机 | 补高度+方向+距离 |
| 动作没有起点/终点 | 中途漂移 | 写"从…到…" |
| 人物左右不固定 | 正反打接不上 | 每镜写画面方位 |
| 连续特写 | 失去空间 | 插一个中景/全景 |
| 用"电影感/高级感" | 无信息 | 换成光向、材质、构图 |
| 时间轴平均分 | 节奏机械 | 按戏剧重量分配 |
| 镜内换空间 | 穿帮 | 拆镜 |

| 平视 / 俯视 / 仰视 / 低角度 / 高角度 | eye-level / high angle / low angle / low angle (ground) / high angle (overhead) |
| 固定 / 缓推 / 拉远 / 横移 / 跟拍 / 升降 / 环绕 / 手持 | static / slow push-in / pull-back / truck / tracking shot / crane / orbit / handheld |

| 过肩 / 主观视角 / 航拍 | over-the-shoulder / POV / aerial |
| 浅景深 / 深景深 / 广角 / 长焦 | shallow depth of field / deep focus / wide-angle / telephoto |

## 12. 光线与氛围写法

> 通用原则（已去绑定）。AI 适配备注为 C 级（项目内约定，未核实），仅作默认值参考，不得当作官方模型行为。

- 主光 practical light only：写明光源是什么、在哪、做什么（烛光 / 窗光 / 月光 / 灯光）。
- 轮廓勾边 rim light / edge light：单侧 45°，人物与背景分离。
- 逆光 backlight + 大面积阴影 shadow-heavy / chiaroscuro。
- 冷暖对撞：冷调环境光 + 暖色点光源（通用写法为「冷环境 + 暖点光」）。
- 氛围介质：heavy atmospheric haze / dust particles（写量词「薄」/「轻」，过量易糊）。
- 低饱和 desaturated / muted color：克制饱和，避免模型拉满色彩。
- 防漂白否定示例（须按题材改写）：不要仙侠光效、不要发光武器、不要游戏海报感、不要 3D 塑料感、不要现代物品乱入（风格化题材慎用）。
- AI 适配备注（C 级）：光线须「一个场景一个光源逻辑」，多光源并列时模型易割裂人物与背景（见 `references/09_去AI感策略库.md` 类别 6）。

## 13. 写前自查清单（写完一条提示词逐项过）

### A. 铁律四查

- [ ] **独立自足**：打开本条闭眼读，不需要「上一条」的任何信息？人物有最小锚、场景有空间关系、时间从 0s 起、衔接只引已定资产？
- [ ] **电影画质**：本条带「超写实电影级摄影 / 真实摄影机型号 / 胶片质感」或 STYLE LOCK？
- [ ] **不为套壳而套壳**：引用知识库提升了本条的具体性（材料 / 光 / 运动学），不是贴模板空话？
- [ ] **音色**：已有音色角色写通用音色描述或音色参考；首登场角色给了详细音色描述并注明入库？

### B. 结构五查

- [ ] 新增资产在首次使用前插入？
- [ ] 母图 / 图像提示词为一个可整块一次性复制的纯提示词块（块内无说明文字）？
- [ ] 每镜有景别 + 焦段 + 机位 + 运镜 + 主体动作 + 台词/音效？
- [ ] 音轨段写了：环境底噪 + 动作拟音 + 标志音 + BGM 有无？
- [ ] 禁止项三类齐全（运动 / 视觉 / 表演）？

### C. 材质与连续性五查

- [ ] 造型清单与已定资产一字不差？
- [ ] 场景空间关系与前镜一致（左右、前后、门的位置）？
- [ ] 180° 轴线在多镜硬切里没跳轴？
- [ ] 台词与原文一致（原对白不可改写腔调）？
- [ ] 首尾帧承接关系写明（上一条尾帧状态 = 本条入点状态）？

### D. 交付前

- [ ] 长度与镜头数标注清晰（按目标模型参数表，不沿用旧口径）；
- [ ] 已确认目标模型与方言（按 `references/03_模型适配.md`，C/D 级标未核实）。

## 14. 长度与拆条

> 以下数字为旧模型上限下的工程口径，**未核实当前模型**，使用时以目标模型参数表（`references/03`）为准。

- **拆条最小原则**：一个原段归并成约 ⌈总秒数 / 单条上限⌉ 条，能 2 条绝不出 3 条；每条各自从 0s 起、独立自足。
- **装箱法**：按镜头顺序装箱，每箱不超过单条上限；放不满时在台词配速内微调单镜时长补满——台词配速正常 4–5 字/秒，拖音 / 意境句 2.5–3.5 字/秒；微调只动时长、不动台词。
- **禁止过短单镜尾巴**：信息密度撑不起来的短尾不单独成条；凑不满时以 10s 起步收尾（旧口径）。
- **一镜到底例外**：整条为一条连续长镜头（缓慢连续拉远 / 画卷横移 / 横移缓推）时可标更长单条；只要含硬切就不标；须在格式行注明并加「禁止硬切 / 跳切」。
- **为什么不能拆太碎**：每条都是一次全新生成，模型不记得上一条——条数越多，跨条造型 / 场景 / 光色越容易漂；同样戏份，少条数省生成次数、少对齐风险。
- AI 适配备注（C 级）：拆条决策只按上述原则，不引用任何旧项目的具体段数据。

## 15. 前 AI 电影语言常识（底层直觉）

> AI 出现前已成熟的电影语言常识，写镜头描述时直接调用；各节末为 AI 迁移备注。

### 15.1 镜头时长与信息密度

- 台词即节奏：口语清晰念诵约 4–5 字/秒；拖音 / 意境句 2.5–3.5 字/秒；屏幕字幕阅读约 1.5–2 字/秒。一句 10–15 字台词镜头至少 4–6s（含开口前 0.3–0.5s 与句尾余韵）。
- 单镜头最小编「立」感：观众认出空间 + 主体约需 3–4s；低于 4s 的镜头只能算「闪过」，除非是刻意的快速节拍。
- 一镜内信息点稀布置：一镜到底的呼吸节奏 = 先环境 / 动作 2–4s 让观众「落座」，再进对白。
- AI 迁移：写时间轴时先心算「这段观众要读几秒」，别让模型把台词硬塞进 3s 短镜。

### 15.2 连续性系统

- 180° 轴线：两人 / 两物对话维持同一侧，跳轴 = 观众迷向。
- 视线匹配 eyeline match：A 看向画面左，切 B 就该在画面右（对着看）。
- 动作衔接 match on action：跨镜动作在运动中途继续，接起来「一气呵成」。
- 30° 规则：同主体连切两次机位差 <30° 会产生「跳变」感（可用作快节奏压迫，不可用于常规对白）。
- AI 迁移：**模型无场记、无记忆**——连续性只能靠三件套撑：① 资产锚定（同一张母图）；② 首尾帧承接；③ STYLE LOCK 光色壳。轴线 / 视线 / 动作衔接由写描述的人自己维持方位一致性。

### 15.3 正反打与三镜头法

- 长对话 = 主镜头（两人同框，交代空间关系）+ 过肩 / 单人特写交替（情绪聚焦），最后切回主镜收束。
- 两话轮配 2–3 镜覆盖是常规；别每一句都换机位（信息密度低、成本高）。
- AI 迁移：对话段镜数按话轮数 / 2 上下即可；对白密度高时宁可加镜长，不要加机位数。

### 15.4 节奏与留白（beat）

- 对白轮次之间留「气口」：一句重话后静一拍（观众消化）。
- 顶点前「静一拍」，顶点后给「反应拍」（观众替角色反应的时间）。
- 一场戏的节奏不是均匀的：快慢交替才有效——全部同长一镜 = 没有节奏。
- AI 迁移：节奏靠镜头时长变化体现（结尾句故意给 7–9s、质问句给 4–5s）；别让模型「均匀呼吸」。

## 16. 站位行格式与轴线管控

> 坐标描述格式本身为本库约定（C 级，未核实），无外部来源背书，不得写成已验证方法。模型是否真按三档位置执行，须以平台复核/实测为准；在此之前，站位行只承诺「写清楚了」，不承诺「模型照做了」。

### 16.1 坐标描述格式（可直接插入提示词，无需改写）

每镜在分镜表「入点 → 出点」之外，另写一行站位行，格式固定如下（直接粘贴进提示词的场景段）：

```text
站位：<人物A>在画面<左1/3|中|右1/3>，<近景/中景/远景>，面向<左|右|镜头>；
<人物B>在画面<左1/3|中|右1/3>，<人物A>的<左|右>侧，相距<一步|一臂|两米>；
镜头轴线：<人物A>—<人物B>连线为轴，机位在轴的<南|北>侧，本镜不越轴。
```

**填写规则**：

- 位置只用三档横向（左 1/3、中、右 1/3）+ 三档纵深（近/中/远），不用「大约」「稍微」这类模糊词；距离只写可感知的步数/臂长/米数其一。
- 每镜的站位行必须与上一镜的出点状态衔接：人物从「门左」到「门右」必须在动作里写清移动过程，不得跳变。
- 站位行是提示词的一部分，不是备注：写进 §4 提示词的场景段，§3 分镜表的「入点 → 出点」列同步写同一站位结论。

**示例**（格式演示，非实测结论）：

```text
站位：女孩在画面左1/3，中景，面向右；捐款箱在画面右1/3，女孩的右侧，相距一步；
镜头轴线：女孩—捐款箱连线为轴，机位在轴的南侧，本镜不越轴。
```

### 16.2 轴线管控

- **建轴**：两人/两物对话或对峙的第一镜，先定轴线（两人连线）与机位侧（轴的哪一侧），写进站位行；后续镜一律同侧。
- **守轴**：多镜头段落维持 180° 轴线，避免跳轴；每镜开拍前先定好两方左右站位。
- **移轴**：必须越轴时，先拍一个「轴上镜头」（人物直视镜头/沿轴线移动的过渡镜）作缓冲，并在分镜表注明「本镜移轴」；无缓冲的越轴 = 观众迷向，复核标 R-04 需修改。
- **反打**：与主镜保持 180° 轴线；反打镜的站位行须与主镜左右镜像一致（主镜人物在左，反打人物仍在同一侧）。

### 16.3 视线与屏幕方向

- 视线方向写进站位行（面向左/右/镜头）；A 看 B 时，A 的视线方向与 B 的站位侧必须一致（A 在左看右，B 必然在右）。
- 移动方向（出画/入画）按屏幕方向写：向左出画的人，下一镜须从右侧入画或已在画外，不得同侧无故重现。
- 动作衔接：上一镜的出点状态（位置、朝向、手持物）= 下一镜的入点状态，逐镜写清；状态跳变是连续性事故的首要来源。

### 16.4 与其他一致性手段的配合

| 手段 | 在站位上的作用 |
|---|---|
| 参考图集（3–8 张） | 锁定人物与场景的相对位置基线 |
| 首尾帧承接 | 上一镜尾帧 = 下一镜首帧，站位无缝 |
| recipe 卡 | 记录轴线侧与站位行，逐镜复现 |
| 站位行（本节 §16.1） | 每镜文字化站位，供模型与复核双重使用 |
