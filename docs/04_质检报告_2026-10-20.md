## 5. 未验证项与残余风险

| 风险 | 等级 | 说明 | 解除条件 |
|---|---|---|---|
| 无真实生成验证 | 高 | 结构 PASS ≠ 成片可用 | 用户带 1 条素材手测样例 02/03，记录失败类型 |
| 平台参数未逐台实测 | 中 | Seedance/Veo/H3/Kling 的 `B/C` 级参数可能过期 | 按当前平台文档复核并更新日期 |
| 仅 Windows + Python 3.14 实跑 | 中 | 脚本按 3.9 语法写，但未在 3.9/Linux 跑 | CI 矩阵（3.9/3.12/3.14 × Ubuntu/Windows） |
| 未在多个 Skill 客户端安装 | 中 | 目录命名、自动加载、相对路径未逐客户端验证 | Claude Code + 另一个兼容客户端各装一次 |
| 没有外部用户手测 | 高 | "3 轮出包"只有内部演练 | 3–5 名外部用户完成 3 轮，记录轮次与卡点 |
| 第三方结构借鉴的许可边界 | 低 | 只抽结构、未复制文案；但未做法律审查 | 公开发布时保留 credits；收到异议即下架相关内容 |
| 序列/多集只有约定 | 低 | 无自动化工具 | 需求出现再做 `plan.json` 校验脚本 |

## 6. 发布建议

1. **可以发私有 beta**：当前版本足以让 3–5 名用户完成"一句话 → 8 节包 → 改一镜"。
2. **暂不公开 GA**：先补三项——外部手测、平台参数复核、干净目录安装测试。
3. **发布时必须保留的边界表述**：不生成视频、平台参数未实测、脚本 PASS 只证明文本自洽。
4. **不建议**把 `_harvest/skill_research/` 的克隆或原文一起分发；它们只是研究证据。
