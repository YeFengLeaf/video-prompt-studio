# 输入 · 同一故事的模型切换

这是 `01_single_story` 的**同故事换模型**样例，用来验证：

> 事实层与分镜表不变，只有执行层（结构顺序、引用语法、参数位置、音频写法）随模型重编译。

**原始输入**：同 `01_single_story/input.md`（雨夜折票，无台词，15 秒）。

**切换目标**：MiniMax H3。

---

## 切换时只改五处

| 层 | 改不改 | 本样例的具体变化 |
|---|---|---|
| 事实层 | 不改 | 人物、场景、道具、台词表逐字保留 |
| 分镜表 | 不改 | 三镜、时长、景别、运镜逐字保留 |
| 提示词结构 | 改 | 变成 `integrated_multimodal_description` + `overall_soundscape` + `non_diegetic_music` 三字段 |
| 引用语法 | 改 | `@Image1` → `<Picture 1>` |
| 参数位置 | 改 | 时间码进入提示词（H3 要求）；时长/画幅仍在参数节 |
