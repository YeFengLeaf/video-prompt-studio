## 2. 三轮演练（完整对话）

### 第 1 轮：用户只给一句话

```text
用户：拍一个雨夜女孩把车票折成纸鹤的 15 秒短片，无台词。
```

Agent 的最短回复（信息够用时**可以不问**）：

```text
我按「单条 15 秒 · Seedance 2.0 · 无台词 · 16:9」做。
只有三件事会改结果：① 一条还是多条？② 跑哪个模型？③ 有没有必须保留的台词/品牌/禁用项？
不回我就按默认走。
```

用户：**"你定。"**

→ Agent 不再追问，进入第 2 轮。技术细节（景别、机位、光、声音）由 Agent 补，写进「决策摘要」。

### 第 2 轮：完整生产包

输出 8 节，结构见 `assets/examples/01_single_story/output.md`。要点：

- §1 决策摘要：逐条写"我替你定了什么"，并列出"仍未知"与"本轮未做"。
- §2 事实层：人物、场景、时间、道具、必须保留项、台词表（无台词也写"无对白"）。
- §3 分镜表：镜号、时间、景别、角度、焦段、运镜、主动作、台词、声音、入出点。
- §4 提示词：整块可复制，块内无解释。
- §5 素材挂图：编号、主职责、作用镜头、不得传递、本条槽位。
- §6 参数：值 + 证据等级 + 说明。
- §7 自检：结构项（脚本）+ 复核项（人）。
- §8 风险：最可能失败、第 3 轮先改哪、未核实项。

### 第 3 轮：只改点名单元

```text
用户：第 2 镜不要俯视，改成侧面跟拍，其他别动。
```

Agent 回复开头必须有一行：

```text
本轮只改：S01-02；其余未动。
```

然后只重写：

```text
## 3. 分镜表（仅改动行）
| S01-02 | 5–10s | 特写 | 侧面 | 85mm | 跟拍 | 把车票折成纸鹤 | — | 纸张折叠声 | 手在口袋 → 纸鹤成形 |

## 4. 提示词（仅改动段）
5–10s：侧面视角，镜头贴着她的手横向跟拍，她把车票对折、再折，折成一只纸鹤。85mm，浅景深。
```

并重跑结构自检，只报受影响项：

```text
S-02 PASS（时间轴未变）· S-03 PASS · S-08 PASS · S-09 PASS
复核提示：R-05 需确认"侧面跟拍"的路径终点是否仍能看清纸鹤成形。
```

**禁止**：顺手改 S01-01 / S01-03、改镜号、清空已确认决定。

## 3. 三个典型场景

| 场景 | 输入 | 输出特征 | 样例 |

## 4. 痛点 → 机制 → 证据

| 痛点 | 机制 | 可验证证据 |
|---|---|---|
| 提示词太简单、缺镜头语言 | 分镜表强制 景别/角度/焦段/运镜/入出点；`02_镜头语言.md` 词典 | `check_package.py` S-01/S-02/S-04 |
| 参数不会调 | 参数表带证据等级 A/B/C/D；未核实项必须显示 | 4 个样例 §6 均含证据列；S-09 防参数泄漏 |
| 多模型切换要重写 | 故事层/执行层分离，只改五处 | `selftest.py` 换模型用例：事实层同=True、分镜同=True、提示词异=True |
| 台词被改写/吞掉 | 台词表 + 逐字进出校验 | S-05；样例 03 的 2 条台词逐字通过 |
| 素材挂错、人物串镜 | 职责矩阵 + 作用镜头 + 槽位 | S-07/S-11/S-13 |
| 模型语法混用 | 方言隔离规则 | 负向测试：Seedance 包用 Veo 校验 → S-08 FAIL |
| 模板占位符被破坏 | 模板校验 + 包内残留检查 | 17 模板/223 占位符 PASS；负向测试 S-10 FAIL |
| 输出像"论文"不能执行 | 8 节合同 + 提示词整块可复制 | `07_输出合同.md`；4 个样例 |
| 把"提示词"说成"成片" | 真实性边界 + 状态机 + 自检只标不评分 | `SKILL.md` §12、`06` §6 |

## 6. 已知限制

1. **没有真实生成验证**：本包不调用任何视频模型；"结构 PASS"不等于"成片好看"。
2. **平台参数未逐台实测**：Seedance 2.0/2.5、Veo、H3、Kling 的时长/分辨率/参考数来自公开文档或项目约定；标 `C` 的必须按平台复核。
3. **语义项不能自动判**：情绪、口型、物理可信度、材质、成片可用性只标"人工"，不打分。
4. **样例是 synthetic**：输入为合成场景，不代表真实客户项目。
5. **序列/多集只给约定**：`references/00` §4 定义了 4 个状态文件，但没有提供自动化工具。
6. **中文为主**：references 与模板以中文写；英文提示词可直接产出（样例 02），但英文文档未单独维护。
7. **运行环境未矩阵化**：脚本按 Python 3.9 语法编写，但只在 Windows + Python 3.14 实跑；Linux / 3.9 / 3.12 未验证。
8. **Skill 客户端未逐一验证**：只按通用 Agent Skills 目录约定组织，未在多个客户端实测自动加载与路径解析。
