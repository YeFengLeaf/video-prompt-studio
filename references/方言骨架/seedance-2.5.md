# 方言骨架 · Seedance 2.5

> 来源：`references/03_模型适配.md` §4。骨架文件：只复述档案，不新增参数。证据等级 B（官方页 + fal，平台相关）。核验日期 2026-10-20。

## 档案

- 单条上限：最长 30 秒（B，官方强调）
- 画幅：21:9–9:16（fal，B，**平台相关，只在确认平台后使用**）
- 分辨率：480p / 720p / 1080p（B，平台相关；2026-10-27 fal API 页复核，见 `references/03_模型适配.md` §11）
- 参考输入：fal：≤30 图 / ≤10 视频 / ≤10 音频 / 合计 ≤50（B，平台相关）
- 音频：原生（B）
- 引用语法：`@Image1` `@Video1` `@Audio1`，与 2.0 相同（B）
- 参数位置：提示词外（B）
- 增量能力：支持 **edit**（改局部、保其余）与 **extend**（续写）；参考控制更细（视觉 / 视频 / 音频分别索引）（B）

## 写法差异（相对 2.0）

- 30 秒不要平均切三段；按"信息点"分，30 秒最多 3–4 个信息点。
- 续写：明确"从哪个状态继续"，不复述已完成动作。
- 编辑：先写"保留什么"，再写"只改哪一处"。
- 平台相关值（fal 的 4–30s / 480p–1080p / 21:9–9:16 / 参考数量）**只在确认平台后使用**，未确认平台时按 2.0 档案保守出包并标「未核实」。分辨率含 1080p 为 2026-10-27 fal API 页复核更正。

```text
光线：{{主光源方向}}，{{明暗关系}}。
声音：{{环境底噪}}；{{动作音}}；{{台词}}。
参考：@Image1 负责{{职责}}；@Video1 负责{{职责}}。
```
