## 档案

- 单条上限：4–15 秒（B）
- 画幅：按平台（B）
- 分辨率：480p–720p（B，按平台）
- 参考输入：图 ≤9 / 视频 ≤3（单条 2–15s）/ 音频 ≤3（单条 ≤15s）/ 合计 ≤12（B）
- 音频：原生音画同步（B）
- 引用语法：`@Image1` `@Video1` `@Audio1`（B）
- 参数位置：提示词外（B）
- 平台合规：不要上传/描述写实真人脸部素材，会被拦截（B）

## 结构顺序

```text
输出目标（要什么样的片子）
→ 参考映射（每个 @ 素材负责什么）
→ 主体与场景锚
→ 动作的时间推进
→ 镜头计划
→ 光线/材质/风格锚
→ 声音计划
```

## 写法规则

- 导演式自然语言，允许 `Setting:` `Action:` `Camera:` `Style:` `Audio:` 短标签。
- 时间轴用 `0–3s：…` 分段，10 秒以上强烈建议分段。
- 每个 `@` 必须写用途：`@Image1 作为主角外观`，不能只写"参考 @Image1"。
- 参数（时长/画幅/分辨率）**不写进提示词**。

## 骨架模板

```text
{{主体}}在{{场景}}，{{动作起势}}。
0–4s：{{建立镜头}}，{{主体状态}}。
4–9s：{{主动作}}，{{阻力/变化}}。
9–15s：{{落点}}，{{收束画面}}。
镜头：{{景别}}，{{机位}}，{{主运镜}}。
光线：{{主光源方向}}，{{明暗关系}}。
声音：{{环境底噪}}；{{动作音}}；{{台词}}。
参考：@Image1 负责{{职责}}；@Video1 负责{{职责}}。
```
