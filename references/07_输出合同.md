# 07 · 输出合同

> 固定 8 节。**少一节不算交付，多一节按需加。**
> 目的是让用户能直接复制、能核对、能只改一处。
>
> **审稿模式例外**：审稿输出为「问题清单 + 最小改动建议」两段式，不适用 8 节齐全要求（见 `00_交互协议.md` §9）；审稿时 S-01 按此例外判。

## 2. 字段定义

| 字段 | 必填 | 说明 |
|---|---|---|
| 镜号 | 是 | `S{条}-{镜}`，如 `S01-02`；条内唯一 |
| 时间 | 是 | `0–4s`；从 0 开始；本镜起止 |
| 景别 | 是 | 远景/全景/中景/中近景/近景/特写 |
| 角度 | 是 | 平视/俯视/仰视/低角度/高角度/过肩/主观 |
| 焦段 | 是 | 35mm 等效；写区间也可（`35–50mm`） |
| 运镜 | 是 | 一个主运镜 + 起点/路径/终点 |
| 主动作 | 是 | 一个；多个就拆镜 |
| 台词 | 否 | 逐字；无则写 `—` |
| 声音 | 是 | 环境 + 动作音 + 人声/音乐/静场 |
| 入点 → 出点 | 是 | 状态变化；跨镜连续性靠这个 |

## 4. 序列/多集的增量

在 8 节基础上补：

```markdown
## 0. 序列台账（放在最前）
| 条 | 时长 | 叙事任务 | 入点状态 | 出点状态 | 依赖上一条 |
```

规则：
- 每条仍从 0s 开始；
- 入点必须等于上一条出点（或明确写"跳切，重置"）；
- 已完成的节拍不能重演；
- 未拍到的未来节拍不能提前泄露。

---

## 5. 不要写进生产包的东西

- 模型名/版本/时长/分辨率**写进提示词正文**（除 MiniMax H3 的时间码）；
- 大段解释塞在提示词代码块里；
- "保证""一定能""电影级品质"这类承诺；
- 未核实却写成确定的参数；
- 用户的原始私密信息（姓名、电话、地址）。
