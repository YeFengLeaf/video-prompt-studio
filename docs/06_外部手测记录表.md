## 1. 目的

对应 `docs/05_发布计划_v1.0.md` 的发布门禁 **G6：外部 3 轮手测**——至少 3 名与作者无关的测试者，各自独立完成一次"一句话 → 生产包 → 改一镜"的完整流程。G6 通过是公开 GA 的必要条件之一（G5–G10 全过才发公开 GA）；G6 未过只发私有 Alpha。v1.1 的准入也要求至少 3 条真实手测记录且没有未关闭的 P0/P1。

## 2. 测试者要求

- 与 Skill 作者无关的外部人员，至少 3 人，互相独立（不互相看对方的输入与结果）。
- 每人会用对话式 AI 工具读入 `SKILL.md` 并按其行事；不需要会写代码。
- 测试者只按 §3 的脚本操作，不由作者在旁提示答案；作者只收记录，不干预过程。

## 3. 测试脚本（每人一次）

1. **第 1 轮**：给一句话创意（自拟，不得照抄 `assets/examples/` 的输入），可带一条约束（如"无台词"或"不要出现品牌"）。
2. **第 2 轮**：回答阻塞问题（或说"你定"），拿到 8 节生产包；检查 8 节是否齐全、台词是否逐字、未核实项是否标明。
3. **第 3 轮**：只改一处（如"第 2 镜换个运镜"），检查其余单元是否逐字不动、改完是否重跑自检。
4. 记下全程：轮数是否超过 3 轮、哪里卡住、哪里表述看不懂、哪里与 `SKILL.md` 承诺不符。

方言覆盖建议（非强制）：3 人尽量覆盖不同方言，至少 1 人用 Kling 或通用方言（Kling 为实验性、未核实，记录时必须写明参数是否被标为未核实）。

## 5. 通过标准

- 3 条记录齐全，每条都独立完成 3 轮内"一句话 → 包 → 改一镜"，且 8 节齐全。
- 发现的 P0/P1 问题全部关闭（修复后由原测试者或另一名测试者复测确认）；只剩 P2 可放行，但须记入 `CHANGELOG.md` 的 Known limits。
- 3 条记录中至少 1 条覆盖 Kling 或通用方言（见 §3 建议）为建议项，不计入 G6 通过判定；覆盖情况如实记录，未覆盖不降级为「部分通过」。

## 6. 未通过时怎么办

- G6 未通过不影响内部自测结论（`scripts/selftest.py` 与 `check_templates.py` 的结果照实记录）。
