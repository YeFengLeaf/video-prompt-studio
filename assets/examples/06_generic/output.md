## 1. 决策摘要

**我替你定的**
- 时长 15s：三个节拍，够建立 + 动作 + 收束
- 画幅按平台：环境叙事为主
- 景别策略：室内中景建立 → 手部特写 → 室外全景收束
- 光线逻辑：台灯为唯一主光源，熄灯后只剩窗外城市灯火
- 声音方案：无对白；办公室环境声 + 开关声 + 脚步声
- 机位：固定 → 缓推 → 缓拉，均在同一侧，不越轴
- 引用写法：通用方言不绑定平台语法，只用自然语言写参考图负责什么

**仍未知的**
- 目标平台的单条时长上限与分辨率（按平台填写）
- 平台参考图入口

**本轮未做**
- 没写角色资产图提示词（用户未要求）
- 没生成视频
